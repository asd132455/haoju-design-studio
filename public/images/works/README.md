# 作品圖片放置方式

把每張作品圖片直接放進對應分類資料夾，網站會在 Astro 建置時自動讀取，不用再手動編輯作品清單：

- `ecommerce/`：電商視覺
- `social/`：社群視覺
- `sales-page/`：銷售頁
- `graphic-design/`：平面設計
- `video/`：影片製作封面

圖片支援 JPG、PNG、WebP、AVIF。檔名請以數字編號開頭，數字越大越新，作品會由新到舊顯示。例如：

- `012-品牌名稱-春季主視覺.jpg`
- `011-品牌名稱-新品活動.jpg`

編號在每個分類內排序；檔名中的品牌名稱與作品名稱會自動作為作品名稱及圖片替代文字。每張圖片會獨立顯示為一件作品。

影片類請先把封面圖放進 `video/`，再把影片的 YouTube、Vimeo 或其他可公開觀看連結貼給我。大型影片檔先不要放進網站資料夾。

如果本機預覽伺服器已經開著，新增圖片後重新啟動 `npm run dev` 才會重新讀取資料夾。上傳到 GitHub 並觸發 Cloudflare Pages 建置後，新作品就會自動出現在對應分類頁。
