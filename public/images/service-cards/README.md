# 首頁輪播卡片縮圖

這個資料夾只存首頁輪播卡片使用的縮圖。替換這裡的圖片不會改動作品案例頁的原始作品。

請保留以下檔名，直接覆蓋要替換的圖片：

- `brand-key-visual.jpg`：品牌主視覺
- `ecommerce.jpg`：電商視覺
- `social.jpg`：社群視覺
- `group-design.jpg`：組圖設計
- `graphic-design.jpg`：平面設計
- `sales-page.jpg`：銷售頁
- `illustration-cards.jpg`：插圖卡片
- `forms-menus.jpg`：表單菜單
- `video.jpg`：影片製作

建議使用橫式、約 1.08:1 比例圖片（例如 1080 × 1000 px）。尚未提供圖片的分類會自動使用其作品資料夾中的第一張作品圖；沒有作品時則顯示品牌底色。
